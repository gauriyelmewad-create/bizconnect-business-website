# 🌐 BizConnect — Business Website

> A production-inspired responsive business website and enquiry portal built with **HTML5, CSS3, and Vanilla JavaScript**.

## 📌 About the Project

**BizConnect** is a modern and responsive business website designed to provide users with an easy way to explore business services, view projects, and submit enquiries.

The project focuses on creating a clean user interface, smooth navigation, responsive layouts, and interactive components using core front-end web technologies.

## ✨ Features

* 📱 Responsive and mobile-friendly design
* 🎨 Modern and clean user interface
* 🧭 Smooth navigation
* 📝 Interactive enquiry form
* ✅ Client-side form validation
* 🖼️ Portfolio/project showcase
* 🔍 Interactive portfolio modals
* 📲 Mobile-first design
* ⚡ Lightweight Vanilla JavaScript
* 🌐 Cross-device compatibility

## 🛠️ Technologies Used

* **HTML5** — Website structure and semantic content
* **CSS3** — Styling, layouts, animations, and responsive design
* **JavaScript** — Interactivity, form validation, navigation, and modals

## 🚀 How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/bizconnect-business-website.git
```

### 2. Open the project

```bash
cd bizconnect-business-website
```

### 3. Run the website

Open `index.html` in your browser.

You can also use **VS Code Live Server** for development.
